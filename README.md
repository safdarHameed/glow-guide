# GlowGuide

Skincare that knows your face and your weather. Scan a selfie with the YouCam AI Skin Analysis API, read live UV,
humidity and air quality for your city, and get a routine of verified products you can buy locally, ranked by AI.

```
glow-guide/
├── frontend/   Next.js 15, React 19, TypeScript, Tailwind CSS v4 (web app on port 3001)
├── backend/    Python 3.12, FastAPI, SQLAlchemy 2 (async), Alembic (API on port 8800)
├── scripts/    setup_local.py: generates local configuration
├── docker/     PostgreSQL init script (creates the test database)
└── compose.yaml  PostgreSQL 16 in Docker (port 55432)
```

## Prerequisites

- Node.js 20+ and npm
- Docker Desktop (running)
- Python 3.12.4 and [uv](https://docs.astral.sh/uv/). If you don't have Python 3.12.4, `uv python install 3.12.4`
  installs it.

## Run locally

**1. Configuration and database** (from the repository root)

```bash
python3 scripts/setup_local.py          # creates .env, backend/.env and frontend/.env.local (git-ignored)
docker compose up -d --wait postgres    # PostgreSQL 16 on 127.0.0.1:55432, data kept in a Docker volume
```

**2. API keys**: edit `backend/.env`

| Variable | Needed for |
| --- | --- |
| `YOUCAM_API_KEY` | Skin scans (YouCam AI Skin Analysis) |
| `GEMINI_API_KEY` | The free AI tier: product search, ranking and routines ([get a key](https://aistudio.google.com/app/apikey)) |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | Optional: "Continue with Google" (hidden when empty) |
| `SMTP_HOST` and related | Optional: without it, password-reset links are printed in the API log |

Database URLs and the JWT secret are generated by the setup script. Without a key, that feature returns a clear
"not configured" message; nothing is faked. Users can also connect their own ChatGPT, Gemini, Grok or
OpenAI-compatible model in **Settings → AI model**.

**3. Backend** (first terminal)

```bash
cd backend
uv venv --python 3.12.4 .venv
source .venv/bin/activate
uv sync --locked
alembic upgrade head
uvicorn app.main:app --reload --port 8800
```

**4. Frontend** (second terminal)

```bash
cd frontend
npm ci
npm run dev
```

Open **http://localhost:3001** and create an account. API docs are at http://127.0.0.1:8800/docs.

**Stopping and restarting:** `docker compose stop postgres` stops the database; run the `up` command again to
start it. Data survives restarts.

cd backend && source .venv/bin/activate
